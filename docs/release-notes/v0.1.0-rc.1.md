## 安装

当前固定安装入口见 README；已核验提交可被安装器发现。默认分支尚无 Skill，不能宣称简短仓库安装命令已可用。全局安装目录不在当前会话可写范围内，尚未实际安装；发现结果不等于安装完成。

## 限制

首版成交为美股正股与期权，IPO 为港股。覆盖不足或字段不完整时标明缺口；资料不足时不生成上涨百分比。不同 Agent 的调度和打开本地文件能力分别遵循其自身支持范围。
